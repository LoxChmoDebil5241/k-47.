# К-47. Нормы расхода плоти. Цикл-48

Интерактивная хоррор-книга с мини-играми в стиле «Signalis × Darkwood».
Вы — читатель, подписавший контракт. В комнате без окон стоит терминал OBJ-4471.
В его архиве 49 глав о клоне К-47. Каждая глава повреждена.
Чтобы прочитать главу чисто, нужно прожить её заново в мини-игре.

Вся игра — **один HTML-файл**: `К-47. Нормы расхода плоти. Цикл-48.html`.

> ⚠️ **18+.** В игре есть насилие, смерть, телесный хоррор, темы самоповреждения и суицида, резкие звуки и вспышки.
> Вспышки и тряску можно отключить: **Меню → Настройки → Эффекты экрана**.
> Игра также учитывает системную настройку «уменьшить движение».

## Как запустить

### Вариант 1. Через GitHub Pages (рекомендуется)

После публикации игра открывается по адресу вида
**https://loxchmodebil5241.github.io/k-47./**
Точный адрес показан в **Settings → Pages** репозитория.

Как включить публикацию (один раз):

1. Откройте репозиторий на GitHub: **Settings → Pages**.
2. В блоке **Build and deployment → Source** выберите **GitHub Actions**.
3. Влейте изменения в ветку `main`.
   Workflow **«Публикация игры на GitHub Pages»** (`.github/workflows/pages.yml`) соберёт игру и выложит её.
   Ход публикации виден на вкладке **Actions**.
4. Перезапустить публикацию вручную можно так: **Actions → «Публикация игры на GitHub Pages» → Run workflow**.

На сайте `index.html` — это сама игра. Рядом лежит копия под исходным именем файла.

### Вариант 2. Просто открыть файл

1. Скачайте `К-47. Нормы расхода плоти. Цикл-48.html`: откройте файл на GitHub → **Download raw file**.
2. Откройте его двойным щелчком в Chrome, Edge, Firefox или Safari. Подходят компьютер, планшет и телефон.

Интернет нужен только для двух вещей:

- **3D-сцен.** Three.js грузится с jsDelivr.
- **Шрифтов.** Они грузятся с Google Fonts.

Без интернета игра полностью играбельна: 3D-сцены заменяются нарисованными 2D-версиями, шрифты — системными.

## Как играть

### Путь

1. **Заставка.** Любая клавиша или касание.
2. **Трудовой договор.** Подпишите кровью — или откажитесь.
3. **Комната.** Осмотритесь: стена с фотографиями, стол с ящиком, проём за спиной, терминал.
4. **Код доступа.** 12 цифр в трёх частях. Они спрятаны в трёх местах: *стол, стена, экран*.
5. **Архив из 49 глав.** Перед чтением повреждённой главы запускается её мини-игра.
6. Дальше — не раскрываем. Норма, проём, капсула, светлый кабинет, тьма.

### Статусы главы

| Статус | Как получить | Что даёт |
|---|---|---|
| **ВОССТАНОВЛЕНА** | мини-игра пройдена | чистый текст главы и запись в блокноте; носитель немного «лечится» |
| **ИСКАЖЕНА** | пройдена «не по архиву» (особый выбор) | текст с помехами и особая запись в блокноте |
| **ПОВРЕЖДЕНА** | провал или «читать повреждённой» | текст с потерями; в режимах «Норма» и «Жёстко» — износ носителя |

Повреждённую или искажённую главу можно перепройти в любой момент: кнопка **«Восстановить заново»** в тексте главы.

### Режимы (Меню → Настройки → Режим)

- **Сюжет.** Износа нет, смерть не страшна.
- **Норма** (по умолчанию). Провалы и смерти изнашивают носитель.
  При 100 % износа носитель ломается: восстановленные главы снова становятся повреждёнными, начинается новый цикл.
- **Жёстко.** Любая смерть — цикл с самого начала.

### Управление

| Где | Клавиатура | Мышь / касание |
|---|---|---|
| Везде | **P** — пауза и меню, **M** — звук | кнопка **⋯** в правом верхнем углу |
| Комната | **← →** / **A D** — стена / стол, **↑** / **W** / **Enter** — терминал, **↓** / **S** — обернуться, **Esc** — назад | кнопки внизу экрана, перетаскивание — осмотреться |
| Терминал | цифры, **Enter**, **Backspace**, **Esc** — выйти | кнопки на клавиатуре автомата |
| Чтение | **← →** — главы, **↓** / **Пробел** — следующий абзац, **A** — весь текст, **T** — оглавление, **N** — блокнот, **Esc** — закрыть | кнопки под текстом |
| Мини-игры | своя схема. Она показана в карточке перед игрой и внизу экрана. **Esc** — прервать (износ не начисляется) | всё управляется касанием |

### Сохранение

Прогресс сохраняется автоматически в `localStorage` браузера. Это главы, блокнот, выборы, износ и номер цикла.

- **Сохранить вручную:** Меню → «Сохранить прогресс».
- **Начать заново:** на заставке кнопка «Начать сначала».

Приватный режим браузера сохраняет прогресс только до закрытия вкладки.

## Для разработчиков

Готовый файл собирается из исходников в папке `k47-src/`. Нужен Node.js 18+, без зависимостей и `npm install`.

```bash
node k47-src/build.mjs            # собрать «К-47. Нормы расхода плоти. Цикл-48.html» в корне
node k47-src/build.mjs --check    # плюс k47-src/.tmp/bundle.mjs для проверки синтаксиса:
node --check k47-src/.tmp/bundle.mjs
```

Что где лежит:

| Путь | Содержимое |
|---|---|
| `k47-src/shell.html` | каркас страницы: `<head>`, шрифты, importmap Three.js |
| `k47-src/body.html` | вся разметка: сцены, модальные окна, оверлеи |
| `k47-src/css/*.css` | стили (склеиваются по порядку имён) |
| `k47-src/js/*.js` | код (склеивается по порядку имён в один модуль) |
| `k47-src/data/book.json` | текст книги: 49 глав |
| `k47-src/deploy/sw.js` | сброс старого сервис-воркера OBJ-4471 на сайте |

Основные модули:

| Файл | Что внутри |
|---|---|
| `00-core.js` | утилиты, сохранение, часы, общий цикл кадров, области ресурсов (`Scope`), модальные окна |
| `01-audio.js` | весь звук синтезируется через Web Audio: эмбиенты и эффекты |
| `02-fx.js` | пост-обработка: зерно, сканлайны, кровь, вспышки, хроматическая аберрация, тряска |
| `03-art.js` | процедурная графика: силуэты, броня, шлем с визором, клон, череп, заставка |
| `10-…16-*.js` | сцены: заставка, договор, 3D-комната и терминал, норма и проём, капсула, психолог, финал |
| `20-games-core.js` | реестр 49 мини-игр и запуск фрагментов |
| `21-…26-games-*.js` | сами мини-игры |

Отладка из консоли браузера:

- `__k47.play(n)` — карточка и мини-игра главы `n + 1` (`n` от 0 до 48).
- `__k47.run(n)` — сразу мини-игра, без карточки.
- `__k47.startAct('room' | 'awake' | 'psych' | 'end' | 'read')` — перейти в сцену.

Внешние зависимости только две: Three.js 0.160 (jsDelivr, importmap) и Google Fonts. Всё остальное — внутри файла.

Старый прототип OBJ-4471 (`index.html`, `src/`, `sw.js` и т. д.) оставлен в репозитории без изменений. Workflow публикует только игру.
