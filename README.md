# К-47. Нормы расхода плоти. Цикл-48

Интерактивная хоррор-книга-игра в одном HTML-файле: 49 глав, у каждой — своя мини-игра.

- **Играть:** открыть `index.html` (или `К-47. Нормы расхода плоти. Цикл-48 (финал).html`) в браузере.
- **Исходники:** `k47/src/` — CSS, разметка, текст книги, модули движка и `games/` (49 мини-игр).
- **Сборка:** `node k47/build.mjs` (с `--check` — проверка синтаксиса) собирает всё в один HTML.

Внешние зависимости: Three.js (jsdelivr) и шрифты Google Fonts.
